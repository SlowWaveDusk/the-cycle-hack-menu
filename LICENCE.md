## 🧩 About

**The Cycle Frontier Helper Menu** is a curated list of The Cycle Frontier open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot tracker, map radar
- **Quality-of-Life Helpers** — inventory notes, config manager, menu notes
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Loot Tracker — highlight nearby containers and loot spots
- Map Radar — compact map overlay for route study
- Run Notes — record and review raid routes
- Session Timeline — review movement for study

### Wallhack
- Overlay Menu — configurable on-screen menu panel
- Custom HUD Notes — organize player HUD elements
- Compact Radar — improved visibility for study

### Aimbot
- Config Presets — segment study on any layout
- Hotkey Control — manual toggle for every panel
- Profile Notes — chain complex configs in the editor
